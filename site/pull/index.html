Your hands-on task

Add your idea.
Open a Pull Request.

Follow these steps in order. You do not need to install anything or use a terminal. You are done when your Pull Request is open and its automated check is green.

Open the practice repository ↗ Sign in to GitHub ↗
1

Sign in to GitHub

Open github.com and sign in. If you do not have an account, create one first.

2

Open the practice repository

Go to github.com/devjadiya/wtb-practice.

3

Make your own copy (fork)

Click Fork near the top-right of the page, then click Create fork. You are now working in your copy of the repository.

4

Open the contributors file in your fork

In your copy, click CONTRIBUTORS.md. Check that the page says your GitHub username near the top. Then click the pencil icon (Edit this file).

5

Add one line at the bottom

Use your name, your Wikimedia username, and one idea for a useful tool. Keep the hyphens and spaces like this:

Your name - Your Wikimedia username - one tool idea

Example: Amina Example - AminaWiki - a tool to find missing citations. Add only your own line. Do not delete anyone else's line.

6

Save your change

Click Commit changes…. Keep the default option to commit to your fork's main branch. Add a short message, such as Add my idea to contributors, then click Commit changes.

7

Open a Pull Request to this repository

On your fork, click Contribute, then Open pull request. Check the destination: the base repository must be devjadiya/wtb-practice and the base branch must be main. Click Create pull request.

8

Check the automated test

Open your Pull Request and look for the Checks tab or the checks near the bottom. Wait for the contributor check to finish.

A green check means your line passed the automatic format test. If it is red, read the message, fix your line in your fork, and commit again. GitHub will update the same Pull Request.

That is all! Leave the Pull Request open. A green check does not merge it; the repository maintainer will review and merge it. You can close the meeting and return to your Pull Request later.
