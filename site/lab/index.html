Reality check: this lab simulates the contributor-format check and review steps. It does not create real Pull Requests, Merge Requests, Gerrit changes, CI runs, or deployments.

Make your contribution and open a Pull Request

No terminal is needed. Follow these steps in GitHub. You are finished when your Pull Request is open and its check is green.

Open the practice repository ↗ Sign in to GitHub ↗
  1. 1

    Sign in and open the repository

    Sign in at github.com, then open the practice repository.

  2. 2

    Make your own copy

    Click Fork near the top-right. Then click Create fork.

  3. 3

    Open the contributors file

    In your fork, click CONTRIBUTORS.md, then click the pencil icon (Edit this file).

  4. 4

    Add one line at the bottom

    Use your name, Wikimedia username, and one tool idea. Keep the spaces around the hyphens:

    Your name - Your Wikimedia username - one tool idea

    Do not remove anyone else's line.

  5. 5

    Save your change

    Click Commit changes…. Keep the default choice to commit to main in your fork. Add a short message and click Commit changes.

  6. 6

    Open a Pull Request to this repository

    In your fork, click Contribute, then Open pull request. Check that the base repository is devjadiya/wtb-practice and the base branch is main. Click Create pull request.

  7. 7

    Check the automated test

    In your Pull Request, open Checks and wait. Green means the format check passed. If it is red, fix your line in your fork and commit again; the same Pull Request will update.

Leave the Pull Request open. A green check does not merge it. The maintainer reviews and merges it.
